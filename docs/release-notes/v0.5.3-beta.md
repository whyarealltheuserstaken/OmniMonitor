# OmniMonitor 0.5.3-beta

**Beta / prerelease.** This is not the final 0.5.0. Prefer the last stable ([v0.4.2](https://github.com/whyarealltheuserstaken/OmniMonitor/releases/tag/v0.4.2)) for day-to-day use unless you want the new Grok and Cursor reads. `/releases/latest` stays on v0.4.2.

Includes [0.5.2-beta](v0.5.2-beta.md) (menu-bar ring, monthly credit cap, Grok Bot meter).

These features have **not been tested against real Grok or Cursor accounts**. Parsers are covered by recorded fixtures and mocked responses. A missing field stays "not available".

## What's new

- **Grok in Cursor tokens.** With the opt-in Cursor provider on, `POST https://cursor.com/api/dashboard/get-filtered-usage-events` is paged. Model names containing `grok` are totaled as **Grok in Cursor** (input, output, and cache tokens). A model is called Grok Bot only when the event's own model or kind says Grok Bot.
- **Overall Cursor tokens and cost.** The same events are also summed for every model, with `tokenUsage.totalCents` shown as dollars, not as tokens.
- **Cursor v2 dollars.** `GET https://cursor.com/api/dashboard/v2/usage-status?scope=user` is preferred over `usage-summary` when `availability` is `available` and `usedCents` / `limitCents` cover the current period. Those cents are shown as dollars.
- **Use signed-in Cursor app.** Off unless you select it (Settings → Cursor). Reads `cursorAuth/accessToken` from the Cursor app's `state.vscdb`. On macOS, a Cursor 3.27+ encrypted token asks once for the "Cursor Safe Storage" Keychain item. In-app sign-in and browser-cookie import stay available. OmniMonitor does not copy or refresh the token.
- **Usage resets left.** `POST https://grok.com/prod_mc_billing.ConsumerUiSvc/GetRemainingResets` uses the existing Grok login token. The line is shown only when that call returns a count.
- **CLI-first Grok read.** `grok agent stdio` tries JSON-RPC `_x.ai/billing`, then `x.ai/billing`, and falls back to the cli-chat-proxy billing call. Timeouts kill the process. Disable it with `omnimonitor config set grok_agent_billing false`.
- **Grok dollars when present.** Deprecated `used` / `monthlyLimit` (US cents) show `$X used of $Y`. Each `history[]` week shows the cents that row contains, as dollars. A missing cap stays missing. These are never shown as tokens.
- **Doctor model-name list.** `omnimonitor doctor` lists the distinct Cursor usage-event model names it saw. Names only: no cookies, costs, or token counts.
- **macOS install docs.** macOS 15 removed the right-click → Open bypass. First launch is **System Settings → Privacy & Security → Open Anyway**, or `xattr -dr com.apple.quarantine` on the app.

## Install or upgrade

Check each download against `SHA256SUMS.txt` (`shasum -a 256 <file>` on macOS, `sha256sum <file>` on Linux, `Get-FileHash <file>` on Windows).

- **macOS:** quit the old OmniMonitor first (menu-bar icon → Quit). Open `omnimonitor-macos-arm64.dmg` (Apple Silicon) or `omnimonitor-macos-x86_64.dmg` (Intel) and drag `omnimonitor.app` onto Applications, replacing the old copy. The same app is attached as a `.zip`.
  - The app is ad-hoc signed only and **not notarized**, so Gatekeeper blocks the first launch. macOS 15 removed the right-click → Open bypass: try to open the app once, then **System Settings → Privacy & Security → Open Anyway**. Or: `xattr -dr com.apple.quarantine /Applications/omnimonitor.app`.
  - The app lives in the menu bar (no Dock icon); on notched MacBooks the icon can hide behind the notch.
- **Linux (x86_64):** `chmod +x omnimonitor-linux-x86_64.AppImage && ./omnimonitor-linux-x86_64.AppImage` (needs FUSE 2; otherwise add `--appimage-extract-and-run`), or unpack `omnimonitor-linux-x86_64.tar.gz` and run `./omnimonitor`.
- **Windows:** unzip `omnimonitor-windows-x86_64.zip` and run `omnimonitor.exe` (unsigned: SmartScreen → **More info → Run anyway**).

## Not verified

- The one macOS Keychain prompt for an encrypted Cursor token was not exercised on a Mac.
- `grok agent stdio` was not run against a real `grok` binary.
- Binaries are ad-hoc signed only (macOS) and not notarized; Windows is unsigned.
