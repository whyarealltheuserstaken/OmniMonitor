# OmniMonitor 0.5.2-beta

**Beta / prerelease.** This is not the final 0.5.0. Prefer the last stable ([v0.4.2](https://github.com/whyarealltheuserstaken/OmniMonitor/releases/tag/v0.4.2)) for day-to-day use unless you want the inner-ring fix and the Grok allowance lines. `/releases/latest` stays on v0.4.2.

Includes [0.5.1-beta](v0.5.1-beta.md) (one menu-bar ring, Grok suite breakdown) and [0.5.0-beta](v0.5.0-beta.md) (opt-in web sessions).

## What's fixed
- **No inner black circle on the menu bar.** 0.5.1-beta kept a wider dark stroke so the ring would show on a light bar. On a dark bar that edge read as a second ring inside the colored arc (seen at 70% left). The gauge is the colored arc and the dim track of the same radius and width.
  - green when ≥ 40% left (`#3FB950`)
  - amber when 20–&lt;40% (`#D29922`)
  - red when &lt; 20% (`#F85149`)
  - Optional % stays beside the ring. Preview: [docs/menubar-ring.png](../menubar-ring.png).

## What's new
- **Monthly USD credit cap**, when `GET https://cli-chat-proxy.grok.com/v1/billing` (same Grok CLI login, without `format=credits`) includes `used` and `monthlyLimit`. Those values are cents. The suite shows dollars. It is not a token allowance. If the fields are omitted, the line says not available.
- **Grok Bot meter:** `usagePercent` from `POST https://cursor.com/api/dashboard/get-sand-usage-status`, only when the opt-in Cursor session is enabled and `hasNonZeroIncludedLimit` is true. A missing percent is not shown as 0%. This meter is separate from the shared weekly pool. The response has no token count and no token cap.
- Missing token counts and the missing token allowance are grouped under **Why some figures are missing**. A billing field that is actually a token limit is shown as the token allowance.

## Install or upgrade

Check each download against `SHA256SUMS.txt` (`shasum -a 256 <file>` on macOS, `sha256sum <file>` on Linux, `Get-FileHash <file>` on Windows).

- **macOS:** quit the old OmniMonitor first (menu-bar icon → Quit). Open `omnimonitor-macos-arm64.dmg` (Apple Silicon) or `omnimonitor-macos-x86_64.dmg` (Intel) and drag `omnimonitor.app` onto Applications, replacing the old copy. The same app is attached as a `.zip`.
  - The app is ad-hoc signed only and **not notarized**, so Gatekeeper blocks the first launch: right-click the app → **Open** → **Open**. On macOS 15+, try once, then **System Settings → Privacy & Security → Open Anyway**. Or: `xattr -dr com.apple.quarantine /Applications/omnimonitor.app`.
  - The app lives in the menu bar (no Dock icon); on notched MacBooks the icon can hide behind the notch.
- **Linux (x86_64):** `chmod +x omnimonitor-linux-x86_64.AppImage && ./omnimonitor-linux-x86_64.AppImage` (needs FUSE 2; otherwise add `--appimage-extract-and-run`), or unpack `omnimonitor-linux-x86_64.tar.gz` and run `./omnimonitor`.
- **Windows:** unzip `omnimonitor-windows-x86_64.zip` and run `omnimonitor.exe` (unsigned: SmartScreen → **More info → Run anyway**).

## Not verified

- The monthly credit cap and Grok Bot meter are tested with fixtures, not live on a personal account in this build.
- Web-session providers remain experimental.
- Binaries are ad-hoc signed only (macOS) and not notarized; Windows is unsigned.
