# OmniMonitor 0.5.0-beta

**Beta / prerelease.** This is not the final 0.5.0. Prefer the last stable ([v0.4.2](https://github.com/whyarealltheuserstaken/OmniMonitor/releases/tag/v0.4.2)) for day-to-day use unless you want to try the new opt-in web-session providers and the colored tray icon.

## What's new
- **Opt-in web-session providers** (off by default): Claude plan, ChatGPT web, and Cursor.
  Per provider you can **sign in in-app** (pywebview on the real login page) or **import
  from a browser** (Firefox / Chrome / Edge / Brave / Arc / Safari where feasible). Only
  that provider's domains and cookie names are read. Sessions go in the OS keyring when
  possible (else a chmod-600 file); they are never logged, exported, shown, or included in
  Report a problem. Sign out / forget per provider.
- Docs: [docs/cookies/](../cookies/) (CodexBar public notes cited; MIT; no code copied).
  Confidence for each new reader is **experimental** until live-verified.

## What's changed
- **Tray icon is green / amber / red by remaining weekly pool** (keeps the ring + optional % Henry liked):
  - green when ≥ 40 % left
  - amber when 20–&lt;40 %
  - red when &lt; 20 %
  - Same thresholds on Windows/Linux gauges. On macOS, colored states are **not** NSImage templates (templates are monochrome); a thin dark+light halo keeps them readable on light and dark menu bars. Error / no-data stay template gray (non-alarm). Demo keeps a blue badge.
- Privacy policy: cookies only for explicitly enabled web-session providers, with a clear Settings explanation.
- CI/Release: Apple Silicon builds on `macos-15` (GitHub retired `macos-14` on 2026-11-02).

## Install or upgrade

Check each download against `SHA256SUMS.txt` (`shasum -a 256 <file>` on macOS, `sha256sum <file>` on Linux, `Get-FileHash <file>` on Windows).

- **macOS:** quit the old OmniMonitor first (menu-bar icon → Quit). Open `omnimonitor-macos-arm64.dmg` (Apple Silicon) or `omnimonitor-macos-x86_64.dmg` (Intel) and drag `omnimonitor.app` onto Applications, replacing the old copy. The same app is attached as a `.zip`.
  - The app is ad-hoc signed only and **not notarized**, so Gatekeeper blocks the first launch: right-click the app → **Open** → **Open**. On macOS 15+, try once, then **System Settings → Privacy & Security → Open Anyway**. Or: `xattr -dr com.apple.quarantine /Applications/omnimonitor.app`.
  - The app lives in the menu bar (no Dock icon); on notched MacBooks the icon can hide behind the notch.
- **Linux (x86_64):** `chmod +x omnimonitor-linux-x86_64.AppImage && ./omnimonitor-linux-x86_64.AppImage` (needs FUSE 2; otherwise add `--appimage-extract-and-run`), or unpack `omnimonitor-linux-x86_64.tar.gz` and run `./omnimonitor`.
- **Windows:** unzip `omnimonitor-windows-x86_64.zip` and run `omnimonitor.exe` (unsigned: SmartScreen → **More info → Run anyway**).
