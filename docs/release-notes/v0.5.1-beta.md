# OmniMonitor 0.5.1-beta

**Beta / prerelease.** This is not the final 0.5.0. Prefer the last stable ([v0.4.2](https://github.com/whyarealltheuserstaken/OmniMonitor/releases/tag/v0.4.2)) for day-to-day use unless you want the menu-bar ring fix and the Grok suite breakdown. `/releases/latest` stays on v0.4.2.

Includes everything in [0.5.0-beta](v0.5.0-beta.md) (opt-in Claude / ChatGPT / Cursor web sessions, green/amber/red tray).

## What's fixed
- **macOS menu bar: one ring.** 0.5.0-beta drew a dark halo and a light halo as wider strokes on the same circle, so the icon looked like three nested rings (seen at 73% left). Colored states are still not template images. A hairline dark edge keeps the single ring visible on a light menu bar; the color reads on a dark bar. No second ring and no filled inner disc.
  - green when ≥ 40% left (`#3FB950`)
  - amber when 20–&lt;40% (`#D29922`)
  - red when &lt; 20% (`#F85149`)
  - Optional % stays beside the ring. Error / no-data stay template gray. Preview: [docs/menubar-ring.png](../menubar-ring.png).

## What's new
- **Grok suite** on the dashboard, mini view, and tray. One weekly total from `creditUsagePercent` on `GET https://cli-chat-proxy.grok.com/v1/billing?format=credits` (the shared pool).
- **Breakdown** from `productUsage` only when the API names the product:
  - Grok CLI — `GrokBuild` (or a literal Grok CLI name). Tokens from `~/.grok/sessions/**/updates.jsonl`. The experimental unified log is the same CLI and is used only when session logs have no usage events.
  - Grok Bot — only a product literally named Grok Bot. Otherwise **not available** (not shown as 0%). `GrokChat` stays Grok Chat.
  - Cursor (Grok) — only a product named Cursor / Grok-in-Cursor. Otherwise **not available**.
  - Any other product the payload lists is shown under its own name.
- A listed product with no `usagePercent` is 0% (proto-JSON omits zero). If the shares do not add up to the suite total, the gap is described and nothing is filled in.
- Grok Bot and Cursor (Grok) token rows say **not available**: those local logs are the Grok CLI. This build does not call Grok Bot's Cursor-account meter or mix in Cursor's plan percent.

## Install or upgrade

Check each download against `SHA256SUMS.txt` (`shasum -a 256 <file>` on macOS, `sha256sum <file>` on Linux, `Get-FileHash <file>` on Windows).

- **macOS:** quit the old OmniMonitor first (menu-bar icon → Quit). Open `omnimonitor-macos-arm64.dmg` (Apple Silicon) or `omnimonitor-macos-x86_64.dmg` (Intel) and drag `omnimonitor.app` onto Applications, replacing the old copy. The same app is attached as a `.zip`.
  - The app is ad-hoc signed only and **not notarized**, so Gatekeeper blocks the first launch: right-click the app → **Open** → **Open**. On macOS 15+, try once, then **System Settings → Privacy & Security → Open Anyway**. Or: `xattr -dr com.apple.quarantine /Applications/omnimonitor.app`.
  - The app lives in the menu bar (no Dock icon); on notched MacBooks the icon can hide behind the notch.
- **Linux (x86_64):** `chmod +x omnimonitor-linux-x86_64.AppImage && ./omnimonitor-linux-x86_64.AppImage` (needs FUSE 2; otherwise add `--appimage-extract-and-run`), or unpack `omnimonitor-linux-x86_64.tar.gz` and run `./omnimonitor`.
- **Windows:** unzip `omnimonitor-windows-x86_64.zip` and run `omnimonitor.exe` (unsigned: SmartScreen → **More info → Run anyway**).

## Not verified
- The single-ring icon was checked with 2× light/dark previews and CI, not on a real Retina menu bar.
- The Grok suite split is tested against fixture billing payloads, not live against a personal account on this build.
- Web-session providers from 0.5.0-beta are still experimental and have not been live-verified on a personal Mac.
- Binaries are ad-hoc signed only (macOS) and not notarized; Windows is unsigned.
