# OmniMonitor 0.4.0

> **Superseded by [v0.4.1](https://github.com/whyarealltheuserstaken/OmniMonitor/releases/tag/v0.4.1)**, which fixes the app staying on demo numbers after the in-app Setup.

This release supersedes v0.3.1.

## What's new
- **Native app window** (pywebview) with an app-style UI: sidebar, dashboard charts, providers, stats and settings.
- **Setup wizard** (`omnimonitor setup` and in the app) that detects provider CLIs and can install them with each vendor's official installer.
- **More providers.** The matrix now has 56 entries: 13 supported, 11 partial, 11 experimental and 21 not supported, each with a reason ([docs/providers.md](https://github.com/whyarealltheuserstaken/OmniMonitor/blob/v0.4.0/docs/providers.md)).
  - New local logs: Claude Code transcripts with ≈5-hour block estimates, Kimi Work shareDir, Pi, Goose and Hermes (partial), and Grok CLI unified log, Antigravity, DeepSeek Harness, OpenClaw, Amp, Factory Droid, Cline, Roo Code and Kilo Code (experimental).
  - New API readers (your own key, env var or `secrets.json` only): Vercel AI Gateway (supported), DeepInfra, Fireworks and xAI month-to-date spend plus spending limit (partial), and Venice and self-hosted LiteLLM (experimental).
  - Documented as not supported, with the reason: z.ai, Volcengine, Hugging Face and Amazon Bedrock.
- **Service status badges** (opt-in, off by default) from official status pages: Claude, OpenAI, GitHub, Cursor, Fireworks and Vercel.
- **Reset countdowns** next to every reset time.
- **Proxy support** (`proxy_url`, CLI or config only).
- **`omnimonitor statusline [--json]`**: an offline one-line summary for shell prompts and tmux.
- Packaging: macOS `.dmg` files (ad-hoc signed app with an Applications link) and a Linux AppImage, in addition to the zip and tar.gz.

**Provider status:**
- **Supported:** Grok CLI sessions, Claude Code, Claude API (organization cost), Codex CLI (+ ChatGPT plan limits), OpenAI API (organization cost), Gemini CLI, Vercel AI Gateway, DeepSeek API, Qwen Code, Kimi CLI / Code / Work, Kimi API (Moonshot) balance, OpenRouter and Ollama Cloud.
- **Partial:** Grok weekly pool, xAI API (prepaid credits and month-to-date spend), DeepInfra, Fireworks AI, GitHub Copilot premium requests, GitHub Copilot CLI (OpenTelemetry file), Cursor (team Admin API), opencode, Pi, Goose and Hermes Agent.
- **Experimental:** Grok CLI unified log, Antigravity, Venice API, LiteLLM proxy, DeepSeek Harness, OpenClaw, Amp, Factory Droid, Cline, Roo Code and Kilo Code.
- **Not supported (reasons in providers.md):** Claude Pro/Max plan limits, ChatGPT app limits, Gemini API, Z.ai, Volcengine Ark, Hugging Face, Amazon Bedrock, Grok Bot, DeepSeek chat app, Qwen API, Kimi app, Cursor individual plans, Ollama (local), Windsurf, Mistral, Perplexity, Zed AI, Kiro, MiniMax, Devin CLI and LM Studio.

## Install

Check each download against `SHA256SUMS.txt` (`shasum -a 256 <file>` on macOS, `sha256sum <file>` on Linux, `Get-FileHash <file>` on Windows).

- **macOS:** use `omnimonitor-macos-arm64.dmg` (Apple Silicon) or `omnimonitor-macos-x86_64.dmg` (Intel). Open it and drag `omnimonitor.app` onto Applications. The same app is also attached as a `.zip`.
  - The app is ad-hoc signed only and **not notarized**, so Gatekeeper blocks the first launch. Right-click the app, choose **Open**, then **Open** again.
  - On macOS 15 and later, try to open it once, then go to **System Settings → Privacy & Security → Open Anyway**.
  - Or, in Terminal: `xattr -dr com.apple.quarantine /Applications/omnimonitor.app`.
  - The app lives in the menu bar (no Dock icon). On MacBooks with a notch the icon can hide behind the notch.
- **Linux (x86_64):** `chmod +x omnimonitor-linux-x86_64.AppImage && ./omnimonitor-linux-x86_64.AppImage`. This needs FUSE 2; without it, add `--appimage-extract-and-run`.
  - Or unpack `omnimonitor-linux-x86_64.tar.gz` and run `./omnimonitor`.
  - The tray needs an AppIndicator host (see the README).
- **Windows:** unzip `omnimonitor-windows-x86_64.zip` and run `omnimonitor.exe`. It is unsigned, so SmartScreen may warn: choose **More info → Run anyway**.
- **First run:** `omnimonitor setup`. On macOS that's `/Applications/omnimonitor.app/Contents/MacOS/omnimonitor setup`.

## Not verified yet
- **Window and tray:** nobody has run them on a real desktop yet. CI launches them on GitHub's macOS and Windows runners (the tray for about 10 s, and a window smoke test that loads the dashboard); the Linux tray is not exercised.
- **New providers:** every provider added in 0.4 is tested against mocked responses only, never with real accounts. Partial and experimental entries may break when vendors change their formats.
- **Signing:** the binaries are not signed with a developer certificate and not notarized (macOS ad-hoc signature only).
- **Platforms:** the AppImage is x86_64 only and has been run only on an Ubuntu CI runner.
