# OmniMonitor 0.6.0-beta

**Beta / prerelease.** OmniMonitor is now a usage and limits monitor for every major AI platform, organised in suites, and it no longer needs a Grok account. `/releases/latest` stays on the last stable ([v0.4.2](https://github.com/whyarealltheuserstaken/OmniMonitor/releases/tag/v0.4.2)).

## What has been tested on real accounts

| Checked on real data (Windows 11, 2026-11-27) | Not tested on a real account (recorded or documented responses only) |
|---|---|
| Claude Code local logs | Website sign-in sources (Claude plan, ChatGPT web, Cursor): the sign-in windows open the providers' real sign-in pages, but no sign-in was completed |
| Claude plan limits via the Claude Code login | Gemini CLI quota and Gemini logs |
| ChatGPT plan limits via the Codex login | Every API-key source (Anthropic, OpenAI, xAI, DeepSeek, Moonshot, Copilot, Cursor team, gateways) |
| The encrypted vault with Windows Credential Manager, and the dashboard window | Codex local logs, DeepSeek / Qwen / Kimi logs and the other coding agents; the Grok weekly pool and Cursor reads |

Grok CLI session logs were checked on real files in an earlier release. The Claude and ChatGPT percentages have not been compared side by side with those vendors' own usage pages. macOS and Linux builds pass CI's automated checks; nobody has used them by hand for this release.

## What's new

- **Suites.** Anthropic, OpenAI, Google, Grok & Cursor, DeepSeek, Qwen, Kimi, GitHub Copilot, API gateways and coding agents are equals. The tray follows a suite you pick, your tightest budget, or the tightest limit across all of them (default).
- **No Grok account needed.** The status command, status line, tray, dashboard and mini view no longer start from the Grok weekly pool.
- **Easy setup.** First run opens a Setup screen that shows each suite as Connected / Found / Sign in / Add key / Not available, with one button each. `omnimonitor setup` does the same in a terminal. API keys are added with `omnimonitor secrets set NAME`, never typed into the page.
- **Plan limits from the CLI logins you already have** (Claude Code, Codex, Gemini CLI): read-only, off until you turn them on.
- **Choose what shows where** (Settings → Layout): order, what appears on the tray icon, tray menu, dashboard, mini view and status line, which numbers each shows, suite colours, alert levels per source or suite, and refresh intervals.
- **Safer sign-in and storage.** Web sessions and API keys are AES-GCM encrypted, with the key in your system keychain. Older plaintext session files and `secrets.json` are moved in on first start. Without a keychain, website sign-in is refused. Sign-in runs in its own process and keeps only allow-listed cookies.
- **`omnimonitor verify`** checks every switched-on source and saves scrubbed results.
- **DeepSeek, Qwen and Kimi:** local logs, plus API balance for DeepSeek and Kimi. There is no website-plan reader for them, and no Qwen balance: no usable source could be confirmed, and OmniMonitor does not guess.

## Fixed

- Cursor sign-in could never finish.
- Release builds did not bundle the encryption libraries, so saved sessions were plaintext files.
- `verify` could not reach ChatGPT and other non-API-key sources.
- `setup` could crash on Windows when there was no input.

## Upgrading

Your config, history and autostart entries are kept. `primary_provider` becomes `tray_suite` automatically.

To report what works on your accounts: run `omnimonitor verify`, look through the saved files, and open an issue with the ones you're happy to share.

## Install or upgrade

Check each download against `SHA256SUMS.txt` (`shasum -a 256 <file>` on macOS, `sha256sum <file>` on Linux, `Get-FileHash <file>` on Windows).

- **macOS:** quit the old OmniMonitor first (menu-bar icon → Quit). Open `omnimonitor-macos-arm64.dmg` (Apple Silicon) or `omnimonitor-macos-x86_64.dmg` (Intel) and drag `omnimonitor.app` onto Applications. The same app is attached as a `.zip`.
  - The app is ad-hoc signed only and **not notarized**. Try to open it once, then **System Settings → Privacy & Security → Open Anyway**. Or: `xattr -dr com.apple.quarantine /Applications/omnimonitor.app`.
  - The app lives in the menu bar (no Dock icon); on notched MacBooks the icon can hide behind the notch.
- **Linux (x86_64):** `chmod +x omnimonitor-linux-x86_64.AppImage && ./omnimonitor-linux-x86_64.AppImage` (needs FUSE 2; otherwise add `--appimage-extract-and-run`), or unpack `omnimonitor-linux-x86_64.tar.gz` and run `./omnimonitor`.
- **Windows:** unzip `omnimonitor-windows-x86_64.zip` and run `omnimonitor.exe` (unsigned: SmartScreen → **More info → Run anyway**).
