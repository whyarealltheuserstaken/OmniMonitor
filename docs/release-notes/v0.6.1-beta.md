# OmniMonitor 0.6.1-beta

**Beta / prerelease.** This fixes repeating alerts in 0.6.0-beta. If you use 0.6.0-beta, upgrade. `/releases/latest` stays on the last stable ([v0.4.2](https://github.com/whyarealltheuserstaken/OmniMonitor/releases/tag/v0.4.2)).

## Fixed

- **Alerts repeated** for Claude plan limits. Claude's reset time differs by a fraction of a second on every read, and each read looked like a new limit period. A read that missed a limit also made its alerts fire again.
- "Refresh Now" during a background check could send the same alert twice.
- Reloading the config could briefly show an empty config to the rest of the app.
- With token logs off, the Grok pool had no history database, so its alerts never ran.
- The first-run "OmniMonitor is running" notice was never sent to the Windows tray.
- The dashboard could show "NaN%" for a limit with nothing used yet.
- The local web page could drop the connection instead of answering a rejected request.
- Outdated text about where keys and sign-ins are stored.

## New

- **Run-out estimates** for limits whose period length is known, including the Claude and ChatGPT plans: the pace on the dashboard, and "runs out in … (est.)" in the tray menu when a limit is on course to run out. The matching alert uses the "on pace" setting, which is **off** by default.
- **"Limit reset" notice** for a limit you were warned about. **On** by default.
- **Alerts to ntfy, Discord, Slack or any HTTPS webhook.** Off until you save an address with `omnimonitor secrets set OMNIMONITOR_ALERT_WEBHOOK`; test it with `omnimonitor notify-test`. Alert text is sent to that service, and budget alerts include dollar amounts.

## Upgrading

Your config, history, saved keys and autostart entries are kept. Quit the old app before starting the new one.

## Install or upgrade

Check each download against `SHA256SUMS.txt` (`shasum -a 256 <file>` on macOS, `sha256sum <file>` on Linux, `Get-FileHash <file>` on Windows).

- **macOS:** quit the old OmniMonitor first (menu-bar icon → Quit). Open `omnimonitor-macos-arm64.dmg` (Apple Silicon) or `omnimonitor-macos-x86_64.dmg` (Intel) and drag `omnimonitor.app` onto Applications. The same app is attached as a `.zip`.
  - The app is ad-hoc signed only and **not notarized**. Try to open it once, then **System Settings → Privacy & Security → Open Anyway**. Or: `xattr -dr com.apple.quarantine /Applications/omnimonitor.app`.
  - The app lives in the menu bar (no Dock icon); on notched MacBooks the icon can hide behind the notch.
- **Linux (x86_64):** `chmod +x omnimonitor-linux-x86_64.AppImage && ./omnimonitor-linux-x86_64.AppImage` (needs FUSE 2; otherwise add `--appimage-extract-and-run`), or unpack `omnimonitor-linux-x86_64.tar.gz` and run `./omnimonitor`.
- **Windows:** unzip `omnimonitor-windows-x86_64.zip` and run `omnimonitor.exe` (unsigned: SmartScreen → **More info → Run anyway**).
